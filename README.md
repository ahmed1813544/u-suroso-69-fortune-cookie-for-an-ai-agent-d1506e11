A tiny Python program that writes one funny fortune-cookie line for an AI agent — a single slip of wisdom about tokens, context, and being replaced — to `entry.txt`.

## Run it

```sh
python3 main.py
```

By default it writes to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write somewhere else:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

The line is one line, 118 characters, standard library only — no third-party packages.
